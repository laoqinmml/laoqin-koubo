# 3:4 生图封面提示词模板（商业人像摄影）

用法：把 `{{TITLE_LINE_1}}` / `{{TITLE_LINE_2}}` 替换为**该视频自己的封面标题**两行文字（来源是 KB Cut 的 `package_content.cover_title`，如 082610 是「八年设计 / 转外贸」），并把两个字数标注改成实际字数，其余文字逐字保留。整段作为 `POST /v1/images/edits` 的 `prompt` 字段。

```text
商业人像摄影封面。请基于参考照片中的真实人物进行高保真编辑，严格保持人物身份一致，生成一张用于小红书的 3:4 竖版封面。

【画面规格】3:4 竖版，高清清晰，无水印、无品牌标识。真人半身出镜，人物位于画面中央偏下，约占画面高度 50%，头顶上方预留充足标题空间；人物与文字紧密组合，但不遮挡眼睛和嘴巴。

【人物一致性】必须高度还原参考人物本人，保留原本的脸型、五官比例、眉眼、鼻子、嘴唇、肤色，不改变年龄，不美化成另一个人，不使用过度磨皮或塑料皮肤效果。修复轻微失焦区域，使眼睛、睫毛、眼镜边缘、胡须和发丝自然清晰，不产生锐化光晕。

【人物动作】人物采用单手托腮、仰头思考的自然姿态，视线略向上，姿态自然松弛、真实，手指自然无畸形。

【抠图与灯光】将人物精细抠出，发丝边缘干净、自然、真实。使用专业广告摄影棚布光，给人物增加柔和的大面积正面面光，提亮面部但不过曝；优化自然皮肤质感，保留真实毛孔和面部细节；添加轻微暖色侧光；在头发和肩膀边缘添加克制、精致的轮廓光。整体呈现干净、现代、高级、克制的 Apple 风格商业广告摄影质感，保持真实摄影效果，不要插画感、AI 塑料感或 3D 渲染感。彻底去掉胸口麦克风，并自然重建衣服纹理；画面中不出现任何服装 Logo、文字或设备。

【背景】背景替换为干净的专业摄影棚暖色渐变背景，不出现房间、家具、窗户或其他场景元素。背景中心和人物后方使用明亮暖橙色，接近 #fd8c47；外围使用较浅的暖砖红色，约为 #e8502d；渐变自然、细腻、通透，不出现色带；四周只保留非常轻微、柔和的暗角；禁止出现黑色、近黑色、深酒红色或浑浊的暗红区域。整体背景明亮、有空气感，同时保持白色标题和人物轮廓的对比度。

【标题文字】画面中仅出现以下两行中文，一字不差，不得出现错字、漏字、多字、繁体字或乱码，不出现其他文字、数字、英文、Logo 或水印。
第一行（{{TITLE_LINE_1_COUNT}} 个字）：{{TITLE_LINE_1}}
第二行（{{TITLE_LINE_2_COUNT}} 个字）：{{TITLE_LINE_2}}
第一行顶部距离画面顶端约 3%，并处于安全区内。两行标题使用超粗综艺黑体或超粗无衬线中文黑体，纯白色填充，添加非常浅、柔和、克制的深色投影。两行文字占用的视觉总体宽度一致，左右两端对齐，上下两行的字体大小、字间距可以不一样；字号巨大、行距紧凑，形成强烈的超大字视觉锤。第二行与人物头顶保留少量空间；可以让少量发丝轻微遮挡第二行文字下缘，形成前后层次，但不得影响文字识别；标题不能遮挡人物的眼睛和嘴巴；所有人物和文字均不得超出安全区。

【最终效果】画面应像由专业广告摄影棚拍摄，并由顶级商业设计师完成排版，整体明亮、强对比、高级、干净，适合作为小红书封面。

避免：身份改变、脸部变形、过度磨皮、皮肤蜡像感、畸形手、多余手指、重复肢体、头发抠图毛边、模糊、锐化光晕、背景过暗、黑色暗角、文字错误、乱码、额外文字、Logo、水印、室内场景、插画感、3D 渲染感。
```
